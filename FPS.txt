코루틴 (Coroutine)
- 유니티에서 제공하는 기능 중 하나.
- 코드의 함수 내에서 어떤 구문을 처리하는 도중에 그 처리를 대기시키고 다른 처리로 넘어가게 하거나, 여러가지 함수를 동시에 병렬로 처리되게 하는 기능 - 비동기 처리 
- 함수에 진입했을 시 그 함수의 끝까지 처리를 하지 않고 중간에 함수 밖으로 나가게 해주는 기능 
- 그리고 함수로 다시 돌아왔을 때 나가기 전에 처리했던 다음 부분 부터 이어서 실행을 하게 해준다.

virtual - override -> 상속 시 같은 이름의 함수를 다른 기능으로 쓰기 위해서 사용
-> override 상속 받은 함수, virtual 상속하는 함수

게임 루프 (Game Loop)
 - 게임이 실행되는 동안 데이터 초기화부터 유저 입력 처리, 게임 세계 업데이트, 화면에 그려주기
 -> 게임 종료 시 까지 계속 반복

		데이터 초기화
		          ㅣ
		입력 받기
		게임 세계 정보 업데이트
		화면에 렌더링
		          ㅣ
		게임 종료
입력 받기 : Input 클래스를 이용해서 키보드 입력, 마우스 클릭, 마우스 커서의 좌표, 터치 위치, 터치를 한 상태인지, 손가락을 뗀 상태인지 등등의 상태를 가져온다.

게임 세계 정보 업데이트 : 클래스의 Update 함수에서 매 프레임 마다 처리할 코드를 넣는다.
			예) 캐릭터의 위치를 매 프레임마다 이동
			      시간의 변화
			      시간이 흐를 때 마다 반복적으로 처리 되어야 하는 것들을 처리
			      Update, FixedUpdata, LateUpdate
Update : 매 프레임 마다 호출, 일반적인 업데이트 처리 시 사용
FixedUpdate : 고정된 주기마다 호출. 물리 처리를 반복적으로 할 때 사용
LateUpdate : Update가 호출 된 이후 호출되는 함수. 카메라 등의 Update 직후에 처리해야 할 것이 있을 때

조명(Lighting)
 - 게임 씬의 전체적인 분위기, 공간감, 실사느낌 조성에 큰 기여
 - 조명을 잘 이용하면 저수준의 모델도 일정 수준의 코퀄리티로 보이게 할 수 있다
 - 사실적인 느낌의 그림자와 명암을 만들어주기 때문

유니티에서 제공하는 조명 시스템의 종류
 - 실시간 조명 (Realtime Lighting) : 실시간으로 계산되는 조명. 부하가 아주 크다.
			         그림자의 방향도 실시간으로 바뀐다.
 - 미리 만들어진 조명 (Baked Light) : 맵상에 배치된 조명과 오브젝트들을 이용해서 미리 텍스처로 만들어 둔다. -> 라이트맵
			             실시간으로 계산하지 않기 때문에 부하가 적다.
			             그림자의 방향 변경 등을 실시간으로 바꾸지 못한다.
 - 혼합 조명 (Mixed Lighting) : 맵상에 고정되어 있는 오브젝트의 경우 미리 만들어진 조명을 적용
			 움직이는 오브젝트의 경우에는 실시간 조명을 적용

조명의 종류
 - Directional Light (방향광) : 멀리서부터 한쪽 방향으로 내리쬐는 조명
			맵의 전체에 영향을 주는 조명
 - Point Light (점광원) : 특정 지점에서 사방으로 퍼지는 빛.  예) 전구, 게임에서는 특정 캐릭터의 위치에 방어막 효과 같은 것을 만들 때
						       던전에서 램프를 켰을 때의 효과
 - Spot Light (스포트라이트) : 손전등, 연극 무대에서 특정 배우만 비추는 조명
