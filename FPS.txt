Time.deltaTime : 이전 프레임에서 현재 프레임까지 실행되는데 소요된 시간
Mathf.Clamp : 범위값을 벗어나지 않도록 보정해줌. 
Quaternion

왼손 좌표계
중지 : x축, 오른쪽 방향이 +
엄지 : y축, 위쪽 방향이 +
검지 : z축, 앞쪽 방향이 +

CharacterController

Vector : 벡터. 오브젝트의 위치(x, y, z), 방향
	- 내적 : 두 오브젝트 사이의 각도
	- 외적 : 방향
Matrix : 행렬. 오브젝트의 이동, 회전, 크기변환
Quaternion : 사원수. 개선된 회전 처리, 매끄럽게 회전

상태 기반
- 게임 내의 모든 오브젝트는 저마다 상태 값을 가진다.
예) 캐릭터 : 대기 상태, 이동 상태, 공격 상태, 피격 상태, 사망 상태
- 3D 툴에서 제작한 애니메이션 데이터를 가져와서 상태를 기반으로 애니메이션을 전환할 수 있게 설정 할 수 있다.

mixamo.com : 애니메이션을 다운로드 할 수 있는 웹 사이트
