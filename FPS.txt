FPS - First Person Shooter (1인칭 슈터)

오늘의 목표
- FPS 게임의 구조 이해
	1인칭 시점 카메라 : 몰입도가 높다. 멀미를 유발 
	WASD키를 사용해서 이동, 마우스로 사격 및 카메라 회전
- 유니티에서 1인칭 시점 컨트롤을 구현
- 마우스 입력을 통한 카메라 회전 처리

Time.deltaTime : 이전 프레임에서 현재 프레임까지 실행되는데 소요된 시간
Mathf.Clamp : 범위값을 벗어나지 않도록 보정해줌. 
Quaternion

왼손 좌표계
중지 : x축, 오른쪽 방향이 +
엄지 : y축, 위쪽 방향이 +
검지 : z축, 앞쪽 방향이 +

CharacterController

Vector : 벡터. 오브젝트의 위치(x, y, z), 방향
	- 내적 : 두 오브젝트 사이의 각도
	- 외적 : 방향
Matrix : 행렬. 오브젝트의 이동, 회전, 크기변환
Quaternion : 사원수. 개선된 회전 처리, 매끄럽게 회전

총알 오브젝트 생성->프리팹 (Bullet, Prefab_Bullet)
프레이어 앞 쪽에 총알을 발사할 위치를 설정 -> 플레이어의 하위에 자식으로 빈 오브젝트를 하나 배치 (Muzzle)
마우스 왼쪽 버튼을 클릭해서 총알을생성해서 발사 -> 앞쪽 방향으로 (GetMouseButtonDown(0), Instantiate, AddFroce)
맵 상에 임의의 오브젝트 배치(tag == "Target") -> 총알에 명중하면 명중한 오브젝트와 총알을 파괴 (OncollisionEnter)
